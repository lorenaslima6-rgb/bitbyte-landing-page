# BiteByte — Landing Page

Landing page oficial de apresentação do **BiteByte**, um robô assistente físico com inteligência artificial voltado para a culinária.

## Sobre o Projeto

O **BiteByte** consiste no desenvolvimento de um robô assistente físico com inteligência artificial, projetado para auxiliar usuários durante o preparo de receitas culinárias de forma prática, intuitiva e personalizada.

O sistema atua como um guia interativo na cozinha, oferecendo instruções em tempo real, adaptadas ao nível do usuário. A proposta é transformar a experiência de cozinhar em algo mais acessível, eficiente e agradável, reduzindo erros e aumentando a confiança durante o processo.
